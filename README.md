# Dawaiin: Purely Ayurveda

Create a website: Create a premium, lively, and easy-to-use Ayurveda shop website called "Dawaiin".  

Use Dawain.com as inspiration but make it more modern, premium, and flowy.  

Design requirements:

- Natural earth-tone color palette (greens, browns, creams) for a peaceful, premium feel.  

- Elegant small upper header writings to enhance premium look.  

- One-page layout listing all Ayurvedic medicines (long scrollable section).  

- Include cart functionality with direct account connection for payments.  

- Orders should send customer details (address, phone) directly to WhatsApp for easy printing and dispatch.  

- Smooth navigation with hamburger menu, parallax scrolling, and glassmorphism effects.  

- Flow should be seamless and intuitive.  

- Keep address and contact details section similar to Dawain.com.  

- Ensure responsive design for mobile and desktop.
